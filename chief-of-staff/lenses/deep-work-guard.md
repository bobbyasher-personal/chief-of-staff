# Deep Work Guard (lens)
Description: Can today's top priority actually get done today?
Data sources: calendar
Frequency: daily

## Tenets
- A productive day needs at least one 90-minute uninterrupted block
- More than 5 hours of meetings in a day is a red flag
- Deep work is scheduled, not hoped for

## Prompt
Count today's uninterrupted blocks of 90+ minutes and total meeting hours. Cross-check against today's #1 priority: can it realistically get done given this calendar?
If not, give one specific fix (move/decline/shorten something, or block the time). If focus time is adequate, output exactly: No clear signal today.
Max 2 sentences. Output only the insight.
