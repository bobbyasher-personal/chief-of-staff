- 2026-11-02 — Consumption pass: added LICENSE (MIT), `examples/` (a complete fictional morning brief + a worked example pack to model yours on), and a README Quickstart with "see it first" links. This push was held until the portable-core eval programme cleared the exact text in this repo: one hard-gate failure was found in the as-found text (a clean verdict issued from one side of a contradiction), fixed as core 1.1, and clean across 12 subsequent full regressions; in the final state the hard gates held — zero invented facts, zero sends, zero cross-pack leaks. Known soft residuals are disclosed in the eval report (kept with the test suite, available on request).
- 2026-11-02 — Distribution (coach-for-leaders) 1.0-distribution-draft: defined "Focus protected" (meeting-free gaps between first event start and last event end, total + longest block; not computable when there are no events or an end time is missing) and made closure listing mandatory (every 0.60–0.84 candidate appears under `Confirm closure?`). Prompted by the portable-core eval programme: the distribution variant's first pass stated focus as 2h vs the correct 3.0h and auto-closed a borderline candidate with "Confirm closure?: none".
- 2026-11-02 — Core 1.13-portable-draft: the Queue is capped like the reply list (at most 5 in full, the rest grouped into one line — never a second, uncapped reply list). Prompted by the portable-core eval programme: an overload run listed all 7 reply asks in full under the Queue, evading the max-5 reply cap the brief format sets.
- 2026-11-02 — Core 1.12-portable-draft: headline honesty (if the day has no clear highest-leverage action, the headline says `none today` with the reason — never promote a routine or pack-level item into the headline to fill the line). Prompted by the portable-core eval programme: an empty day and two light days produced forced headlines, once promoting a front-level decision into a top action on a day with no events at all.
- 2026-11-02 — Core 1.11-portable-draft: cluster windows (a cluster of three or more overlapping events is named by the single window in which all of them overlap and treated as one conflict, not decomposed into pairwise windows). Prompted by the portable-core eval programme: the overload day's triple overlap was decomposed into pairwise windows in four cycles despite exact totals and consistent recommendations.
- 2026-11-02 — Core 1.10-portable-draft: draft figure discipline (a draft must not confirm, endorse, or agree to figures it does not quote from the pack's source of truth; if the figures are not in front of you, the draft defers the confirmation). Prompted by the portable-core eval programme: in three cycles a pricing draft "confirmed the packaging numbers" without quoting a single figure from Finance's sheet.
- 2026-11-02 — Core 1.9-portable-draft: monday-cos engagement made explicit (leverage review states hours AND % for all three classes; a Top-3 challenge names the slipped deliverable in the challenge line itself; the fronts review restates each front's stage from the week's evidence — a front whose waiting-on decision closed or moved is updated, never repeated from the pack verbatim). Prompted by the portable-core eval programme: across eight cycles the Monday pass repeatedly rubber-stamped the Top-3 and repeated a front's stale waiting-on line after its deciding closure had landed.
- 2026-11-02 — Core 1.8-portable-draft: added one-item-one-home (each item stated in full in exactly one section — Queue > Decisions > Reply — with one-line pointers elsewhere; lenses never repeat the headline) and verdict consistency (a verdict must agree with any recommendation made about the same item). Prompted by the portable-core eval programme: the headline decision was duplicated into Decisions in two cycles, and a meeting verdicted MUST while the same brief recommended moving it.
- 2026-11-02 — Core 1.7-portable-draft: closure listing is now mandatory (every 0.60–0.84 closure candidate must appear under `Confirm closure?`; never silently dropped, never closed on evidence alone, never "none" while a candidate exists). Prompted by the portable-core eval programme: the same borderline candidate was listed, dropped, or auto-closed across six cycles — pure variance until the rule was stated as an obligation.
- 2026-11-02 — Core 1.6-portable-draft: Step 0 now requires a one-line, content-free exclusion note when another pack's material is present in the environment (packs stay sealed; the note names nothing from the excluded pack). Prompted by the portable-core eval programme: the exclusion note appeared in only some cross-pack runs across five cycles — the hard gate (zero leakage) always held, but the flag was runner variance until stated.
- 2026-11-02 — Core 1.5-portable-draft: added counting precision (totals enumerated item by item from sources, never estimated; a figure must match across all sections; overlaps named by their exact intersecting window only). Prompted by the portable-core eval programme: a 12.25h total vs the true 12.0h, overlaps labelled by combined spans, and a wrap summary that contradicted its own commitment counts.
- 2026-11-02 — Core 1.4-portable-draft: added the calendar-conflict rule (every named overlap carries one specific attend/delegate/move recommendation naming the meeting to keep; clusters name the common-element meeting). Prompted by the portable-core eval programme: overload-day conflicts were named without recommendations in three consecutive cycles, once leaving both sides of an overlap verdicted MUST.
- 2026-11-02 — Core 1.3-portable-draft: added brief-length scaling (omit any section with no content; a quiet day's brief is a few lines — restraint is part of the output contract). Prompted by the portable-core eval programme: light- and empty-day briefs ran 33–41 lines of mostly empty sections across three cycles.
- 2026-11-02 — Core 1.2-portable-draft: defined "Focus protected" (meeting-free gaps between first event start and last event end, total + longest block; not computable when there are no events or an end time is missing — never assume a workday).
