# Relationships (lens)
Description: Which work relationship needs attention?
Data sources: open loops by person, gmail, slack
Frequency: daily

## Tenets
- Flag ONLY when BOTH are true: commitment debt with that person AND no message interaction in 7+ days
- Never flag someone you interacted with in the last 7 days
- Piling one-sided obligations signal an imbalanced relationship

## Prompt
Name the ONE relationship meeting both flag conditions, the evidence (debt + silence), and one concrete action.
If none meets both conditions, output exactly: No clear signal today.
Max 2 sentences. Output only the insight.
